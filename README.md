Questo repository, è dedicato all'implementazione di un parser robusto ed efficiente, focalizzato principalmente su una variante semplificata del formato JSON 
(JavaScript Object Notation). Il progetto esplora anche l'integrazione strategica di una struttura dati Trie (albero prefisso) per migliorare le prestazioni e le capacità di parsing.
Il contesto di questo progetto è un incarico accademico, che trae i suoi requisiti e le sue specifiche principali da PEL-unive/progetto-23-24.
